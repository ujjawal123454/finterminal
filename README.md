# FinTerminal

A real-time Indian financial market dashboard built with FastAPI + vanilla JS.

## Features
- 📈 Live NIFTY / BANKNIFTY / FINNIFTY straddle charts
- 📊 Full Option Chain with IV, Greeks, Buildup
- 🌍 Global Markets (Brent, NASDAQ, Gold, USD/INR)
- 📋 IPO & Bonds tracker with GMP
- 📉 FII/DII institutional flow
- ⚡ Market Pulse — live pullers/draggers scanner
- 🔐 Admin panel for Kotak Neo API management

## Run Locally

```bash
cd backend
pip install -r requirements.txt
python server.py
```

Open: http://localhost:3000
